Multi-Line Insurance Policy and Claims Management System

This project standardizes Auto, Property and Life quoting, routes claims to product queues, and provides a focused adjuster dashboard. High-value claims require two sequential approval decisions.

Demo scope: This browser application demonstrates workflows with synthetic data stored on this device. It is not connected to a Salesforce org. Salesforce deployment and Apex coverage must be validated separately.
Milestone 1 · Data and configuration

Policy and Claim custom objects, product record types, field sets, data validation and three quoting Screen Flows.

Milestone 2 · Premiums and routing

Bulk-safe PremiumCalculator preserves request order and supports repeated policy IDs. Claim routing resolves queues by DeveloperName and follows the linked policy's record type. State stamping touches only the triggering claim.

Milestone 3 · Lightning dashboard

ClaimsAdjusterController queries the current owner's workload using sharing and user-mode field permissions. claimsDashboardLwc adds search and filters; claimTileLwc shows metrics and opens the claim.

Milestone 4 · Approvals and security

High-value approval process routes to Senior Adjuster then Department Manager. The approval screen processes pending work items assigned to the caller. Private object sharing, state groups and separate Agent, Adjuster and Manager permission sets support restricted access.
